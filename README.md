# Morning Coffee

I was using [Newsboat](https://newsboat.org/) on my laptop to follow a bunch of RSS feeds. It's a lightweight TUI client that's pretty good at its job. But at the same time, I wanted a reader I could use on other machines too without the overhead of synchronizing its state across multiple devices. That's how I got the idea to create this project.

Morning Coffee produces a plain, boring HTML page with links to the latest entries from feeds it's configured to follow. There is no interactivity or additional functionality\*. In this regard, my project cannot replace Newsboat or any other proper RSS client, but it fully\*\* satisfies my needs.

\* Okay, there _are_ a few lines of JS, but it's totally optional and can work with NoScript.
\*\* This might or might not change.
